# Code of Conduct

This project expects respectful, direct, professional collaboration.

## Expected Behavior

- Focus on technical substance
- Assume good intent, but be precise about risks and tradeoffs
- Respect user privacy and security boundaries
- Keep criticism specific to code, design, and process

## Unacceptable Behavior

- Harassment, intimidation, or personal attacks
- Publishing private information without consent
- Deliberately unsafe instructions or changes that violate the project privacy model
- Disruptive behavior that makes collaboration materially harder

## Reporting

Report conduct issues to `me@danmunoz.com`.

Maintainers may remove comments, close discussions, or block contributors when necessary to protect the project and its users.
